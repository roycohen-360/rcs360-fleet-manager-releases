# RCS360 Fleet Manager — installers

This repository holds only the Windows installers and the update feed (`latest.yml`) that installed copies of RCS360 Fleet Manager check at launch. The source code is private.

The newest installer, always at the same address:
https://github.com/roycohen-360/rcs360-fleet-manager-releases/releases/latest/download/RCS360-Fleet-Manager-Setup.exe

The app requires an active RCS360 subscription.
